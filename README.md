## Description

Ce programme est un module logiciel qui permet de gérer des missions de livraison de pilules
en envoyant des instructions à des opérateurs de drone pour qu'ils opèrent ces drones à partir de différentes bases.

Pour lancer le programme, ouvrir un terminal dans le répertoire
du projet puis exécuter :
